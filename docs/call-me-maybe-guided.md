# Call Me Maybe Guided Pack

The development pack is intentionally kept in the ignored local directory:

`_local/packs/call-me-maybe-guided`

It contains eight levels (Days 05 through 12) and 32 progressive activities.
The pack uses `workspace.scope: pack`, so the user's project is shared at
`training/call-me-maybe-guided/project`. Existing files are preserved while
new starter paths are introduced.

The activity matrix and subjects live beside the local pack in `MATRIX.md` and
the individual `subject.md` files. Day 13 is not an activity; it remains a
manual delivery checklist for synchronization, lint, clean execution, custom
paths, Git, and final execution.

The pack is not bundled or imported automatically. During development, point
the normal local-pack/import flow at the directory explicitly.
